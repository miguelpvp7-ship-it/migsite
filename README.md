# MIG CS2 — versão para cPanel

Versão do site adaptada para alojamento cPanel (Node.js + PostgreSQL), sem Netlify.
Segue o ficheiro **TUTORIAL-CPANEL.md**: tudo se faz no cPanel, sem instalar nada no PC.

O script `build:site` compila o site para `dist/client` e o servidor para `dist/app.cjs` (ficheiro de arranque).
